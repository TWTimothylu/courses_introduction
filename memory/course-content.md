## 4. 各課程資料與改寫文案

### 4.1 簡易樂高機器人班｜essential

**來源事實（S1）**

採用 SPIKE Essential，以圖像指令控制簡易機器人；涵蓋組裝、空間認知、簡單機械、程式思考與自行改裝。課堂透過引導協助孩子找問題、嘗試解法，也結合無障礙設計、環境保育等生活議題。設備不需自備。

**改寫文案**

- 主標：第一台機器人，從孩子的想法開始。
- 短介紹：用熟悉的樂高積木，加上一個個圖像指令，讓親手組裝的作品動起來。在搭建與改裝之間，練習觀察、思考與嘗試。
- 三個重點：搭出自己的機器人／用圖像指令安排動作／發現問題，再動手改一改。
- 詳細介紹：孩子先動手組裝，再試著用程式控制作品。動作和想像不一樣時，老師會引導孩子觀察：是哪個地方需要調整？還能怎麼做？讓每一次修改，都成為理解機械與程式的機會。
- 家長選課提示（編輯建議）：喜歡拼搭、對會動的作品好奇，可先從這門課認識機器人。
- 行動按鈕：預約免費體驗 → trial.html?course=essential

### 4.2 樂高機器人班｜prime

**來源事實（S2）**

使用 SPIKE Prime 和積木式程式，從機器人組裝、機械原理進入程式控制與任務設計，練習拆解及解決問題。沿用生活議題與教師引導的教學方式。

教具規則：第一期由教室免費提供；第二期起原頁鼓勵因進階學習與比賽需要自備，也列有續用教室設備的選項。自備享三期、每期折 1,200 元；使用教室教具每期另付 2,000 元。優惠起算期、購置價格及其他限制原頁未詳述。

**改寫文案**

- 主標：自己造的機器人，自己寫指令。
- 短介紹：讓拼搭不只停在完成模型。透過積木式程式，設計機器人的動作，再用一次次任務挑戰，練習把想法變成可行的解法。
- 三個重點：理解機構怎麼運作／用程式控制作品／拆解任務、測試與改良。
- 詳細介紹：機器人要完成任務，機構和程式都得一起思考。孩子在組裝與操作中找出問題，修改設計，再觀察結果。老師提供方向，讓孩子有機會自己判斷與嘗試。
- 家長選課提示（編輯建議）：喜歡實體拼搭，也想探索程式如何控制機器人，可考慮這一班。
- 行動按鈕：預約免費體驗 → trial.html?course=prime

### 4.3 Scratch 程式班｜scratch

**來源事實（S3）**

原頁亦稱 Scratch 程式遊戲班。使用 Scratch 進行遊戲創作，包含角色、關卡、道具設計與電腦繪圖，以積木程式練習邏輯、運算思考及問題拆解。頁面標示無需自備教具；電腦是否一人一台、是否可借用到家，未說明。

**改寫文案**

- 主標：不只玩遊戲，也能設計自己的遊戲。
- 短介紹：角色長什麼樣子？關卡要怎麼過？把孩子對遊戲的好奇，帶進角色繪製與程式設計，試著做出自己的互動作品。
- 三個重點：畫出角色與道具／組合指令設計遊戲／拆解想法，逐步完成作品。
- 詳細介紹：Scratch 將程式指令變成可以組合的積木，讓孩子把注意力放在遊戲怎麼運作。從畫面到互動，一邊創作、一邊測試，在作品調整中練習清楚表達想法與解決問題。
- 家長選課提示（編輯建議）：對遊戲、角色或畫面創作有興趣，可從這門課認識程式。
- 行動按鈕：預約免費體驗 → trial.html?course=scratch

### 4.4 樂高機器人 Python 班｜robot-python

**來源事實（S4）**

使用 SPIKE Prime 搭配 Pybricks Python。課綱含齒輪比、連桿、槓桿，以及 Python 語法、條件、迴圈、函式、模組化、感測器與馬達控制。原頁以自走車導航、機械手臂、任務自動化為專題例子，並將 AI、物聯網及演算法列為未來可銜接方向，並非本期完整教授的承諾。

首期未自備者由教室免費提供。第二期起，自備教具享三期、每期折 1,200 元；續用教室教具另付 2,000 元。是否另需自備電腦未明列。

**改寫文案**

- 主標：讓 Python 指令，成為機器人的動作。
- 短介紹：從實體機器人走進文字程式。結合機構設計、感測器與馬達控制，讓孩子看見自己寫下的指令，如何在真實世界運作。
- 三個重點：探索進階機構／以 Python 控制機器人／透過專題拆解與完成任務。
- 詳細介紹：不只讓機器人動起來，也思考它如何完成任務。課程將 Python 語法與機器人實作連在一起，在設計、測試與修改之間，練習有條理地安排程式與解決問題。
- 家長選課提示（編輯建議）：想學文字程式，又喜歡操作實體機器人的孩子，可與老師討論是否適合。是否需先修經驗，原頁未訂明。
- 行動按鈕：預約免費體驗 → trial.html?course=robot-python

### 4.5 Python 程式班｜python

**來源事實（S5）**

內容包含變數、型別、運算子、條件、迴圈、函式、模組套件與例外處理；資料結構涵蓋字串、列表、字典、集合及巢狀結構。以情境任務、終端小遊戲、自動化工具與簡易爬蟲練習，搭配流程圖、偽程式、單元測試及除錯。需自備 Windows 或 macOS 筆電，未提供硬體規格。

**改寫文案**

- 主標：把生活裡的想法，寫成可以執行的程式。
- 短介紹：從 Python 基礎開始，透過小遊戲與實用工具，練習把問題拆成步驟，再用程式一步步完成。
- 三個重點：建立文字程式基礎／整理與運用資料／在專題中練習測試及除錯。
- 詳細介紹：寫程式不只是記住語法。孩子會從任務出發，思考需要哪些資料、步驟如何安排，以及出錯時該怎麼檢查。透過持續實作，逐步累積編寫程式與解題的經驗。
- 家長選課提示（編輯建議）：希望以電腦上的軟體作品為主，探索遊戲或小工具製作，可考慮這門課。
- 行動按鈕：預約免費體驗 → trial.html?course=python

## 5. 共用品牌文案與選課架構

以下為編輯建議，不是來源頁的新增事實。

**品牌主標**：讓孩子的想像，真的動起來。

**品牌介紹**：從一塊積木到一行程式，讓孩子在親手創作中學習。遇到問題時，老師陪孩子觀察、思考與嘗試，讓作品的每一次改變，都成為理解與成長的機會。

**選課區標題**：找到孩子想探索的下一步。

**選課區說明**：先選擇孩子的年級，再看看他想做機器人、設計遊戲，還是寫出自己的程式工具。

**區別兩門 Python 課**：機器人 Python 以實體機器人為載體，重點連結機構、感測器與動作控制；Python 程式班以電腦上的程式作品為主，重點在語法、資料處理與解題。兩者不是同一門課換名稱。

**區別兩門樂高課**：簡易班用 Essential 與圖像指令；樂高機器人班用 Prime 與積木式程式，加入機構與任務設計。不能僅用價格區別。

**呈現順序**：適合對象 → 一句話介紹 → 三個學習重點 → 課堂照片／作品 → 上課方式與費用 → 預約體驗。重要資訊放在同頁，避免必須多次跳轉才能理解課程。

## 6. 可用 FAQ 草稿

**需要先會寫程式嗎？**
簡易樂高班、樂高機器人班與 Scratch 使用圖像或積木式指令；兩門 Python 課有基礎語法內容。孩子的年級、經驗與學習節奏仍需由老師協助評估，原頁未定義統一先修門檻。

**每一期上多久？**
各班一期 12 堂，每堂 1.5 小時。實際開班日期、每週頻率與補課方式，這五頁沒有提供。

**需要準備什麼設備？**
簡易樂高與 Scratch 原頁記載無需自備教具。兩門 Prime 機器人課有首期提供、續期自備或使用費規則。Python 程式班需自備 Windows 或 macOS 筆電。

**報名體驗後就確定上課時間嗎？**
不是。依現有報名流程，送出代表收到體驗意願；家長需加入官方 LINE，主動告知孩子姓名，由老師確認課程及時間。
